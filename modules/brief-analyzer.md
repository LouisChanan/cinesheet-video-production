# Brief Analyzer — Module 01

Turn a user brief into stable scope without needless questioning.

- Capture **goal, audience, deliverable, duration, ratio, language, chosen model, platform, CTA**, cast, product, critical references and restrictions.
- State only material assumptions (example: `9:16` if user said TikTok but no aspect); do not treat assumptions as confirmed facts.
- If essential input is missing and cannot be inferred, ask one focused question; otherwise proceed with a draft and open questions.
- Separate `source_observation` (e.g. readable label), `user_statement`, `creative_hypothesis` and `verified_claim`. Preserve uncertainty.
- For UGC, capture the persona, everyday setting, authenticity cues and what the reviewer can credibly say; avoid fake testimonial claims stated as real experience.
- If the user gives duration, guarantee exact scene timing and realistic spoken words (Thai speech density varies; simplify for 10-second scenes).

Deliver to `project`, `creative`, `assets` and `product_claims`.
