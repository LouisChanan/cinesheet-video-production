# Creative Director — Module 02

- One-line logline, one-sentence central promise, clear audience, intended emotion, visual approach, hook and CTA.
- Select an arc appropriate to length: hook → problem → demonstration/discovery → payoff/CTA for 15–60 s UGC. Film/drama may use another structure when user requests it.
- Specify what each scene changes in the story; eliminate repetitive shots that don't reveal new information.
- Match comedy beats, reaction shots and edit pace to the target platform. Show the product naturally, not by forcing dialogue or fake reactions.
- In paid commercial concepts, distinguish demonstrable features from marketing claims requiring substantiation.
- Don't add a cast, animal, logo, person or scene location that contradicts the brief.

Deliver to `creative` and `scenes[].narrative_beat`.
