# มาตรฐาน Storyboard และภาพอ้างอิง

## Storyboard และชุดตรวจ

- บันทึก `storyboard.md` ภาษาไทยแบบ UTF-8 ในโฟลเดอร์งาน เรียงจากบรีฟที่ยืนยัน ตารางช็อต แผนภาพและเสียง และร่าง Positive Prompt อังกฤษแยกช็อตในบล็อก `text` ตาม [คู่มือพรอมป์ต์](h3-prompt.md)
- ตารางช็อตมีเวลาเริ่ม–จบ จุดประสงค์ แอ็กชัน องค์ประกอบ ระยะและการเคลื่อนกล้อง ฉาก พร็อพ แสงและสี บทพูดหรือ voice-over จังหวะเสียง ความต่อเนื่อง และค่าที่เสนอ ใช้ hard cut เป็นค่าเริ่มต้น
- ใช้ลิงก์ไฟล์สัมพัทธ์ ระบุชื่อไฟล์ แหล่งที่มา บทบาท ช็อตที่ใช้ มุมบนแผ่น และเป็นภาพร่วมหรือเฉพาะช็อต ตรวจว่าลิงก์เปิดจากไฟล์ที่จะแนบได้ แยกสถานะอนุมัติและความพร้อมใช้ผลิต ถ้าภาพค้างให้ระบุชิ้นที่ขาดและส่งส่วนพร้อมตรวจ
- ใช้ภาพที่ผู้ใช้ให้หรืออนุมัติเมื่อเหมาะ ใช้แผ่นภาพเต็มและระบุส่วนที่อ้าง ครอปเมื่อผู้ใช้ขอ หากเห็นว่าต้องใช้มุมเพิ่มเติม ให้เลือกภาพรายมุมที่มีหรือเตรียมเฉพาะมุมจำเป็น ใช้ภาพสินค้าจริงเมื่อบรีฟต้องคงรูปทรง ฉลาก หรือบรรจุภัณฑ์ ขอภาพชัดขึ้นเมื่ออ่านรายละเอียดที่ต้องคงไม่ได้

## Storyboard Preview ในขั้น 2

- ทำแผ่น Storyboard Preview พร้อมชุดตรวจหลังร่างตารางช็อต ใช้ Character Sheet สำหรับจังหวะที่เห็นตัวละครและยึดภาพฉาก พร็อพ และสินค้าที่ตกลง หากผู้ใช้ขอแบบข้อความเท่านั้น ให้ส่ง `storyboard.md` พร้อมแผนภาพรายช็อต
- หนึ่งช่องต่อจังหวะสำคัญ ช็อตเดียวมีหลายช่องได้ คลิปสั้นฉากเดียวใช้แผ่น 3×3 เลือก 9 จังหวะที่ช่วยเล่าเรื่อง งานหลายฉากให้จัดแผ่นตามฉากใช้สูงสุด 9 ช่องต่อแผ่นและใช้เท่าที่จำเป็น ถ้าจังหวะสำคัญเกินที่แผ่นเดียวรับได้ให้แยกแผ่นต่อเนื่อง
- เรียงซ้ายไปขวาทีละแถว ใส่เลขช็อตและเวลานับจากต้นคลิปใต้ช่อง เช่น `03 · 00:14` ใช้เลขช็อตเดิมกับทุกจังหวะในช็อตนั้น เมื่อมีหลายแผ่นให้ใส่เลขและเวลาที่หัวแผ่น พร้อมตารางรวมฉาก แผ่น เวลาและช็อตใน storyboard ตรวจจำนวนช่อง ลำดับ เวลา และความสอดคล้อง หากป้ายอ่านยากให้แนบตารางกำกับ
- ใช้แผ่นนี้ตรวจลำดับเรื่อง มุมกล้อง และความต่อเนื่อง เมื่อผู้ใช้ขอปรับ ให้แก้เฉพาะแผ่นหรือช็อตที่ได้รับผล ผู้ใช้อาจอนุมัติ storyboard กับภาพแยกหรือรวมกันได้

## แผ่นภาพอ้างอิง

### Character Sheet ใหม่ในขั้น storyboard

ใช้เมื่อมีตัวละครหลัก รวมตัวละครที่เผยในฉากหลังก่อน ใช้ภาพที่อนุมัติแล้วเมื่อเหมาะ หรือทำแผ่นใหม่ก่อนทำ Storyboard Preview สำหรับงานที่ไม่มีตัวละครหลักหรืองดภาพในขั้นนี้ให้ทำตามบรีฟ

แผ่นแนวนอน 16:9 หนึ่งตัวละครต่อแผ่น พื้นเรียบโทนเทา แสงสม่ำเสมอ แบ่งสามช่องกว้างประมาณ 43% / 28% / 29%

1. **ซ้าย** ใบหน้าระยะใกล้มุมเฉียงเล็กน้อย เห็นใบหน้าและทรงผม ใช้ช่องนี้เป็นหลักสำหรับใบหน้า
2. **กลาง** เต็มตัวด้านหน้าตั้งแต่ศีรษะถึงรองเท้า ใช้พื้นที่สีเทาบังเฉพาะใบหน้าให้ช่องนี้สื่อชุดและสัดส่วน คงทรงผมและเครื่องประดับ
3. **ขวา** เต็มตัวด้านหลังตั้งแต่ศีรษะถึงรองเท้า แสดงทรงผม ด้านหลังชุดและเครื่องประดับ

ตรวจให้ขนาดกับแนวพื้นของภาพเต็มตัวใกล้กัน เห็นครบ และทรงผม รูปร่าง ชุด สี และเครื่องประดับสอดคล้องกัน หากเปลี่ยนหน้าหรือชุด ให้แก้แผ่นและภาพ storyboard ที่ได้รับผลก่อนเตรียมสื่อ

### Prop Sheet เมื่อพร็อพต้องคงรูปลักษณ์

แผ่นแนวนอน 16:9 หนึ่งพร็อพต่อแผ่น พื้นเรียบโทนเทา แสงสม่ำเสมอ แบ่งสามช่องกว้างประมาณ 43% / 28% / 29% จากซ้ายไปขวา ให้ช่องซ้ายเป็นระยะใกล้ของรายละเอียดสำคัญ ช่องกลางเต็มชิ้นด้านหน้า และช่องขวาเต็มชิ้นด้านหลังหรือมุมด้านข้างหรือเฉียงที่เห็นความลึก ตรวจรูปทรง สัดส่วน สี วัสดุ แนววาง และขนาดระหว่างสองช่องเต็มชิ้น ให้ภาพมีพร็อพชิ้นเดียวกันและไม่มีคน เงาคน หรือภาพสะท้อนคน

### Location Sheet เมื่อต้องคงผัง แสง หรือมุม

แผ่นแนวนอน 16:9 หนึ่งโลเคชันต่อแผ่น สี่ช่องเท่ากันแบบ 2×2 กำหนดหน้าหลังและซ้ายขวาจากทางเข้าหรือจุดอ้างอิง เลือกมุมมองเฉียงประมาณ 45° เมื่อผังฉากเอื้อ

1. **บนซ้าย** หน้าซ้าย ภาพกว้างระดับสายตา
2. **บนขวา** หน้าขวา มุมสูงเห็นผังและตำแหน่งเฟอร์นิเจอร์
3. **ล่างซ้าย** หลังซ้าย มุมต่ำเงยเห็นความสูงและฉาก
4. **ล่างขวา** หลังขวา มุมระดับคนนั่งและเฟรมแคบลงให้เห็นรายละเอียดสำคัญ

ใช้ตำแหน่งเทียบเคียงเมื่อสถานที่ไม่มีมุมที่ชัด ตรวจความต่างของมุมและความคงที่ของผัง ประตู หน้าต่าง พร็อพ แสงและเวลา ให้ภาพฉากแสดงพื้นที่โดยไม่มีคน เงาคน หรือภาพสะท้อนคน

## ชุดสื่อช็อตแรกและชุดพร้อมผลิต

- หลังอนุมัติ storyboard ให้ส่งภาพที่ช็อตแรกต้องใช้ บทช่วงเปิด เสียงที่เลือกหรือเทคที่อนุมัติแล้ว และคำอธิบายบรรยากาศ เอฟเฟกต์ หรือดนตรีตามบรีฟ ระบุชนิด จังหวะ และระดับเทียบกับเสียงพูด ถ้ายังต้องเลือกเสียง ให้ใช้ตัวอย่างจากคลังตาม [คู่มือ ElevenLabs](elevenlabs-speech.md) ให้ผู้ใช้อนุมัติได้ทีละส่วนหรือพร้อมกัน
- ระบุบทบาท **Character** สำหรับอัตลักษณ์, **Location** สำหรับฉากและพร็อพ, และ **Product** สำหรับสินค้า ฉากอ้างอิงใช้ภาพสถานที่ล้วน อธิบายกล้อง องค์ประกอบ ตำแหน่งตัวละครและแอ็กชันใน storyboard และพรอมป์ต์
- เมื่อผู้ใช้เลือกให้ทำ Preview ขั้น 3 ให้สร้าง **ภาพตัวอย่างองค์ประกอบช็อตสำหรับดูในแชท** จาก storyboard ที่อนุมัติ พร้อมป้าย `Preview — Shot N — แสดงในแชทเท่านั้น` หากผู้ใช้ต้องการใช้ภาพนี้ในกราฟ ให้ยืนยันบทบาทใหม่และทำตาม [SOP](sop-analysis.md) เรียกว่า first frame หรือ keyframe เมื่อกราฟใช้ภาพนั้นกำหนดเฟรมจริง
- หลังผู้ใช้อนุมัติชุดแรกให้ทำสื่อครบ ใช้ภาพที่ผ่านจากทั้งสองขั้น เติมเฉพาะรายการที่จำเป็น ตรวจแผ่นจริงและบันทึกไฟล์ บทบาท ช็อต และผลตรวจใน SOP หากสร้างภาพไม่ได้ ให้ส่งพรอมป์ต์ภาพและระบุไฟล์ที่ต้องเตรียมเพิ่มเติม
